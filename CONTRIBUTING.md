# Contributing

This project is an 8-week, master’s-portfolio ASIC study. The easiest way to help is to complete or review **one sprint at a time**.

1. Read [docs/02_eight_week_sprint_plan.md](docs/02_eight_week_sprint_plan.md).
2. Read [docs/01_status_and_roadmap.md](docs/01_status_and_roadmap.md) so you do not redo Experiment 0.
3. Open the current week under [docs/sprints/](docs/sprints/).
4. Keep work in the existing folders (`algorithm/`, `rtl/`, `verification/`, `designs/`, `results/`, `docs/`).
5. Do not commit OpenLane source, PDKs, virtualenvs, VCDs, or simulator binaries.

If you are new to the stack, the sprint overview lists the minimum skills. Do not expand scope into a CPU, a large neural net, or a custom PDK.
